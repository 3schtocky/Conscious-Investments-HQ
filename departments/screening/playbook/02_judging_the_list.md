# Screening playbook: judging the list

Work down the top ~15 and give each name a verdict: **dig**, **drop** or **watch** (interesting, not ready). One line of reasoning each.

## Sanity checks before you trust a rank
1. **Look at the revenue line, not the growth rate.** Is the latest quarter in line with the quarters around it, or a spike? A name growing 150 percent off a tiny base is not the same as one growing 40 percent on a real base.
2. **Look for the cause.** Ask what changed: a product ramp, a new contract, pricing, a market opening. If you cannot name the cause from a filing or a credible source, it is not yet a thesis.
3. **Check the margin move is earned.** Gross margin up because of mix or scale is good. Up because of a one-time credit or a reclassification is not.
4. **Data staleness.** An old quarter, a missing factor (counted as neutral), a restated number, or a share count that predates a split can all fake a good score. Name it and drop it, or mark `[VERIFY]`.
5. **Dilution and funding.** For loss-makers: runway in years, recent raises, converts, and what the next raise would do to existing holders.
6. **Concentration.** One customer, one product, one government program. Fine, if named as the main risk.
7. **Liquidity.** Could {captain} actually own it? Average daily traded value near the $5 mn floor is a flag.

## Choosing the shortlist
- Prefer **variety of cause**: if three names are the same trade (all riding one theme), keep the best one and say the others are the same bet.
- Prefer **evidence you can source** over a higher score you cannot explain.
- Return **up to five**. If only three survive, return three and say why the rest failed. An honest short list beats a padded one.
- Rank the final names and give a one-line "why this one, why now".

## When to stop
- If the screen cannot run or returns a thin or stale universe, report that and stop; do not improvise a list from memory.
- If nothing passes, say so plainly. Reporting "no good ideas today" is a valid, valuable result.
